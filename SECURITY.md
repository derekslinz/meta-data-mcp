# Security Policy

## Supported Versions

Security fixes are applied to the **latest released version** only.
Older versions are not actively supported.

| Version  | Supported          |
| -------- | ------------------ |
| latest   | :white_check_mark: |
| < latest | :x:                |

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Report security issues privately via GitHub's built-in advisory system:

1. Go to the repository's **Security** tab.
2. Click **"Report a vulnerability"** under the *Advisories* section.
3. Fill in the description and, if possible, include reproduction steps and
   affected version(s).

You can also open a private advisory directly at:
<https://github.com/derekslinz/meta-data-mcp/security/advisories/new>

### What to expect

- We aim to acknowledge reports within **3 business days**.
- We aim to release a fix or mitigation within **14 days** of confirmation
  for high/critical severity issues, and within **30 days** for medium/low.
- We will coordinate disclosure timing with you before making the advisory
  public.
